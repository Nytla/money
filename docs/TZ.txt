Сервис учёта доходов / расходов на Next.js
1. Вход в систему будет по паролю;
2. Войдя в сервис видим таблицу дохов / расходов за текущий месяц, а над таблицей функционал;
3. Функционал над таблицей это:
 - возможность вывыести любой другой месяц или целый год данных;
 - Кнопка "Добавить доход";
 - Кнопка "Добавить расход";
 - Кнопка "Добавить категорию расхода" - например Покупки, Комуналка, Инвестиции, Благотворительность и т.п. жедательно чтобы можно было загрузить иконку;
 - Кнопка "Добавить доход";
 - с права Кнопка "Выбор валюты";
 - с права кнопка "Выгзузить в Ексель";
 - с права кнопка "Сменить пароль";
 - с права кнопка "Выход";
4. Столбцы у таблицы по порядку:
 - Месяц, год (месяц, гггг);
 - Дата Доходов;
 - Доходы, (тут выбранная валюта);
 - Дата Расходов (дд.мм.гггг);
 - Расходы, (тут выбранная валюта);
 - Остаток, (тут выбранная валюта;
 - Десятина, %;
5. Также можно добавить такую вещь как кнопка "Статистика" в виде графика:
 - статистика по остастку финансов в конце каждого месяца за выбранный период;
 - статистика по инвестициям в каждом месяце за выбранный период;
 - статистика по благотворительности  в каждом месяце за выбранный период;
 - ...
 - суть раздела статистика такова, выбрать Категорию, период и построить наглядную стасистику по данной категории за выбранный период.
